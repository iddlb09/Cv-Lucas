#CV Lucas

Este projeto consiste no desenvolvimento do meu currículo digital interativo, criado com o objetivo de unir design e prática de programação front-end.

Sobre o Projeto:
O currículo foi inicialmente desenvolvido em formato PDF, utilizando uma IDE para estruturar e estilizar o layout.
A partir dessa base visual, decidi transformá-lo em uma versão web interativa, utilizando HTML, CSS e JavaScript, como forma de aprimorar minhas habilidades em desenvolvimento e dar uma identidade mais dinâmica e moderna à minha apresentação profissional.

Objetivos do Projeto:
Praticar e consolidar conhecimentos em desenvolvimento front-end.

Criar uma versão digital e interativa do currículo.

Explorar conceitos de design responsivo e boas práticas de UI/UX.

Demonstrar organização, clareza e estilo profissional na exposição das informações.

Tecnologias Utilizadas:
HTML5 – Estrutura do conteúdo

CSS3 – Estilização e layout responsivo

JavaScript – Interatividade e animações leves
